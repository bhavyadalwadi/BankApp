# BankApp

Static banking website prototype with a landing page, login flow, enroll and forgot-password pages, account page, and mortgage-oriented content.

## What this repo does

- shows a bank-style landing page with login UI and marketing sections
- provides static enroll and forgot-password pages
- includes account-related page flows
- loads shared navigation and footer partials
- includes mortgage-oriented content and supporting assets

## Main files

- `index.html`
  - main landing page and login entry
- `account.html`
  - account-related page flow
- `enroll.html`
  - enrollment page
- `forgot.html`
  - forgot-password page
- `_script/script.js`
  - client-side interactions and shared front-end behavior
